# Session handoff

Private per-user session memory lives under `~/.session-memory/sessions/<repo>/`.

## Resume

1. From the repo root, run `session-memory show` (or `session-memory latest` for the path).
2. Read the digest. Treat Requirements and Decisions as binding.
3. Continue from Next step. Use the matching `*.log.md` only if you need more detail.

## Checkpoint

When asked to checkpoint or update the session digest:

1. Summarize the current conversation into JSON:

   ```json
   {
     "decisions": ["Use the checkpoint command to save summaries."],
     "current_state": ["Implementation complete; tests pass; changes are uncommitted."],
     "open_questions": [],
     "next_step": "Review and commit the changes."
   }
   ```

   These four fields are required. `current_state` must contain at least one item;
   `next_step` must be a non-empty string. Use `[]` when there are no decisions or
   open questions/blockers. Optional `goal` (string), `requirements` and
   `corrections` (arrays of strings) replace those sections when provided; omit
   them to keep the existing content. Include meaningful test results, unfinished
   work, and uncommitted changes in the current state. Do not invent progress.
2. Save the JSON to a temporary file and run
   `session-memory checkpoint --session <current-conversation-id> --input <json-file>`
   from the repo. Pass the current conversation's ID when known. Without
   `--session`, the command uses `CODEX_THREAD_ID` if set, otherwise the latest
   digest for this repo/branch. If no ID is available, inspect `session-memory show`
   to verify the target belongs to this task. Do not update the previous session's
   injected handoff. If the command reports no digest, check that the hooks are
   installed and the current session has submitted a prompt; do not silently use
   another session.
3. Report the saved digest path. The command validates the update, preserves the
   previous version under `sessions/<repo>/history/`, and replaces the digest
   atomically. Never edit `*.log.md` — it is auto-generated by hooks.
